Step B — Deploy backend JAR
On your PC (with Java 21):

cd stwmovers-backend
mvn -DskipTests package
scp target/stwmovers-backend-1.0.0.jar root@91.108.102.169:/opt/stwmovers/backend/app.jar
On VPS:

chown stwmovers:stwmovers /opt/stwmovers/backend/app.jar
systemctl start stwmovers-backend
journalctl -u stwmovers-backend -f
Wait for Flyway migrations and Started TaxiBookingApplication.

Step C — Build & deploy frontend on VPS
apt install -y git
cd /opt/stwmovers
git clone https://github.com/mhassanjut/cabservice.git repo
cd repo/stwmovers-frontend
npm ci
export NUXT_PUBLIC_API_BASE_URL=https://api.stwmovers.com
export NUXT_PUBLIC_GOOGLE_MAPS_API_KEY=your-key
export NUXT_PUBLIC_GOOGLE_CLIENT_ID=your-client-id
export NUXT_PUBLIC_STRIPE_PUBLIC_KEY=pk_test_...
npm run build
cp -r .output /opt/stwmovers/frontend/
chown -R stwmovers:stwmovers /opt/stwmovers/frontend
systemctl start stwmovers-frontend
journalctl -u stwmovers-frontend -f
Update config/site.ts siteUrl to https://stwmovers.com before building (or set via env if you wire it).
