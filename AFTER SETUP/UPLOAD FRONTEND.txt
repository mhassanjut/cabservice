
Step 1 — On the VPS: get the code
cd /opt/stwmovers
git clone https://github.com/mhassanjut/cabservice.git repo
cd repo/stwmovers-frontend
If the repo is private, use SSH clone or upload the folder with scp.
Step 2 — Create production .env
nano /opt/stwmovers/frontend/.env
Paste (fill in your real keys):
NUXT_PUBLIC_API_BASE_URL=http://api.stwmovers.com
NUXT_PUBLIC_GOOGLE_MAPS_API_KEY=your-maps-key
NUXT_PUBLIC_GOOGLE_CLIENT_ID=your-google-client-id
NUXT_PUBLIC_STRIPE_PUBLIC_KEY=pk_live_or_pk_test_...
Use http:// until Certbot SSL is done. After SSL, change API URL to https://api.stwmovers.com and rebuild.
Copy the same values from your local .env if you’re using test keys for now.
Step 3 — Build on the VPS
cd /opt/stwmovers/repo/stwmovers-frontend
# Load env for build (Nuxt bakes NUXT_PUBLIC_* into the bundle)
export $(grep -v '^#' /opt/stwmovers/frontend/.env | xargs)
npm ci
npm run build


Next steps (from where you are now)
Step 4 — Copy build output to the service directory

cp -r /opt/stwmovers/repo/stwmovers-frontend/.output /opt/stwmovers/frontend/
chown -R stwmovers:stwmovers /opt/stwmovers/frontend
Step 5 — Start the frontend

systemctl start stwmovers-frontend
journalctl -u stwmovers-frontend -f
Step 6 — Verify

curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/
Then open http://stwmovers.com in a browser.
