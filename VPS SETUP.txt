STEP 1 — Get Your VPS IP Address
Go to hPanel → VPS → click Manage next to your server → scroll down to the VPS details card to find your IPv4 address. Copy it — you'll need it for DNS and SSH. Hostinger

IPv4: 91.108.102.169

STEP 2 — Point DNS to Your VPS IP
Go to the Domain Portfolio page on hPanel → click Manage next to stwmovers.com → select DNS / Nameservers from the left sidebar. Hostinger
Then in the DNS records section, create or update these three records:
TypeNameValueA@YOUR_VPS_IPAwwwYOUR_VPS_IPAapiYOUR_VPS_IP
Delete any existing A, AAAA, or CNAME records that include @, www, or cloudflare-resolve-to before adding the new ones. DNS propagation may take up to 24 hours.


STEP 3 — Access Your VPS Terminal
On the VPS Overview page in hPanel, click the Terminal button in the top right corner. A new window opens and you are automatically logged in as root. This is the easiest way — no SSH client needed. Hostinger

STEP 12 — Configure Nginx
Create the main site config:
bashnano /etc/nginx/sites-available/stwmovers
Paste this:
nginx# Frontend — stwmovers.com
server {
    listen 80;
    server_name stwmovers.com www.stwmovers.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}

# Backend API — api.stwmovers.com
server {
    listen 80;
    server_name api.stwmovers.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
Enable the config:
bashln -s /etc/nginx/sites-available/stwmovers /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx


STEP 13 — Create systemd Units
Backend service:
bashnano /etc/systemd/system/stwmovers-backend.service
ini[Unit]
Description=STW Movers Spring Boot Backend
After=network.target postgresql.service

[Service]
User=stwmovers
WorkingDirectory=/opt/stwmovers/backend
ExecStart=/usr/bin/java -jar /opt/stwmovers/backend/app.jar
EnvironmentFile=/opt/stwmovers/backend/.env
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
Frontend service:
bashnano /etc/systemd/system/stwmovers-frontend.service
ini[Unit]
Description=STW Movers Nuxt Frontend
After=network.target

[Service]
User=stwmovers
WorkingDirectory=/opt/stwmovers/frontend
ExecStart=/usr/bin/node /opt/stwmovers/frontend/.output/server/index.mjs
EnvironmentFile=/opt/stwmovers/frontend/.env
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
Enable both:
bashsystemctl daemon-reload
systemctl enable stwmovers-backend
systemctl enable stwmovers-frontend

STEP 14 — SSL with Let's Encrypt

⚠️ Only run this after DNS has fully propagated (Step 2). Verify with ping stwmovers.com returning your VPS IP first.

bashcertbot --nginx -d stwmovers.com -d www.stwmovers.com -d api.stwmovers.com
Follow the prompts — Certbot will automatically update your Nginx config for HTTPS and set up auto-renewal.
Verify auto-renewal works:
bashcertbot renew --dry-run
