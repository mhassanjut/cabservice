Production checklist (Hostinger KVM 2)
Full guide: docs/PRODUCTION-DEPLOYMENT.md

Before / during VPS setup
Point DNS: stwmovers.com, www, api.stwmovers.com → VPS IP
Install Java 21, PostgreSQL, Node 20, Nginx, Certbot, UFW
Create DB user/database; keep Postgres on localhost only
Create /opt/stwmovers/backend and /opt/stwmovers/frontend
systemd units for stwmovers-backend and stwmovers-frontend
Nginx: stwmovers.com → Nuxt :3000, api.stwmovers.com → Spring :8080
SSL: certbot --nginx (free Let's Encrypt)
Backend .env on VPS (/opt/stwmovers/backend/.env)
DB_*, JWT_SECRET (new 48+ char secret — not dev)
CORS_ORIGINS=https://stwmovers.com,https://www.stwmovers.com
STRIPE_API_KEY / STRIPE_WEBHOOK_SECRET (Live mode)
STRIPE_SUCCESS_URL / STRIPE_CANCEL_URL (production URLs)
GOOGLE_CLIENT_ID, Brevo SMTP (MAIL_*), ADMIN_EMAIL / ADMIN_PASSWORD
CAR_UPLOADS_DIR=/opt/stwmovers/backend/uploads/cars
Frontend build env
NUXT_PUBLIC_API_BASE_URL=https://api.stwmovers.com
Maps key, Google OAuth client, pk_live_...
Set siteUrl in stwmovers-frontend/config/site.ts to https://stwmovers.com
Stripe (production)
Complete Stripe business verification
Switch to Live mode
Webhook: https://api.stwmovers.com/api/v1/payments/webhook
Use sk_live_..., whsec_..., pk_live_...
Run a small real payment test
JWT
Generate production-only secret; store only on VPS + GitHub secrets
Never commit; rotating it logs everyone out
Google
OAuth: authorized origins https://stwmovers.com
Maps API key: HTTP referrer restrict to your domain
Search Console domain verification (DNS TXT)
Email
Verify domain in Brevo (SPF/DKIM/DMARC)
Test OTP/booking emails from production
Security
Change default admin password after first deploy
Daily Postgres backups + uploads/cars/ backup
Review Admin/creds.txt on main — if it has real credentials, remove from repo and rotate those secrets
Smoke test after deploy
Home → book → cars → Stripe → confirm; admin login; car image upload; route pricing; pickup city validation.
