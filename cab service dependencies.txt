🚀 3. Dependencies (VERY IMPORTANT)

For a cab booking system, you need a solid base:

🔥 CORE DEPENDENCIES
1. Spring Web
REST APIs for Next.js frontend
2. Spring Boot DevTools
Auto reload during development
3. Spring Data JPA
ORM for database handling
4. PostgreSQL Driver
Production-grade database (recommended for booking systems)
🔐 SECURITY (important for later)
5. Spring Security
Authentication (users/drivers/admin)
🧾 VALIDATION
6. Validation (Jakarta Validation)
Input validation for booking, login, etc.
🧠 OPTIONAL BUT HIGHLY RECOMMENDED
7. Lombok
Removes boilerplate code (getters/setters)
8. Spring Boot Actuator
Health checks (important for production)
🧰 API QUALITY (VERY USEFUL)
9. Springdoc OpenAPI (Swagger UI)
API documentation for frontend integration
🌍 OPTIONAL (if needed later)
Spring Security JWT (we’ll add manually later, not via initializer)
Redis (for caching rides, optional later)
🧾 FINAL INITIALIZER CHECKLIST

✔ Spring Web
✔ Spring Data JPA
✔ PostgreSQL Driver
✔ Spring Security
✔ Validation
✔ Lombok
✔ DevTools
✔ Actuator
✔ OpenAPI (Swagger)
